# 前端验收与优化（2026-10-11）

通过 computer-use 操作本地 Streamlit 页面，并使用真实 ETF 行情检查加载、下载与进阶计算。验收环境为 Python 3.9.6 / Streamlit 1.50.0，使用 Codex 内置浏览器。

## 发现与修复

| 检查项 | 处理 |
| --- | --- |
| 点击下载 CSV 后看板回到初始提示，指标和图表消失 | 各分析动作分别保存最新结果与输入；普通 rerun 保留结果 |
| 运行 GBM 会清空已显示的归一化图 | 四类结果独立保存，组合编辑只使组合结果失效 |
| 开始日期晚于结束日期时仍能启动计算 | 参数栏即时提示并禁用相关按钮，代码为空时仅禁用单标的分析；美债默认 10Y 例外保留 |
| 进阶页默认展开的代码参考表使组合输入和运行按钮远离区块说明 | 输入与按钮前移，代码参考表折叠；归一化与 GBM 可单独收起 |
| 320px 宽度下第三个标签被截断 | 简化说明页标签、收紧标题与页面上方空间，三个标签完整可见 |
| 组合收益、波动与权重用小数展示，不方便阅读 | 图表坐标与悬停显示百分比，权重表显示百分比；原始数值与算法不变 |
| 进阶图固定暗色样式，浅色主题下部分曲线对比度较弱 | 统一图表基础模板并跟随 Streamlit 主题，调整曲线配色，用虚线区分模拟中位数 |

结果仅保存在当前会话，最多保留每类分析的一个结果。对应资产、日期、代理或组合输入变化后清除旧结果；刷新浏览器开启新会话时仍需重新运行。失败重试会清除上次成功结果，错误保留至修正输入或再次执行，避免错误与旧数据混淆。

没有改变 OHLCV 接口、复权、基金与收益率图表分流、指标公式、252 日 GBM、500 条模拟路径、5000 个随机权重组合或固定随机种子。页面仍使用原生 Streamlit 组件，没有增加前端框架。

使用独立离线样本启动 Streamlit 1.28，并通过 computer-use 复现了更实质的问题：搭配 Plotly 7 时 K 线缺失，价格序列被错误画成 0–120 的递增曲线。根据图表序列化数据及 [Plotly 官方迁移说明](https://plotly.com/python/v6-migration/)，推断为旧版前端与新版数组格式不兼容。Web 最低版本提高至已验证的 Streamlit 1.50；当前用户环境无需升级。旧版 AppTest 本身的格式化 selectbox 错误未通过修改产品逻辑绕过。
